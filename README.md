# Rock Paper Scissors — Python Console Game
This is a simple little Rock‑Paper‑Scissors game I built in Python. It runs in the console and lets you play as many rounds as you want. You pick rock, paper, or scissors, and the computer randomly chooses its move. The game tells you instantly whether you won, lost, or drew, and you can exit any time by typing quit.

## What the game does
Lets you play unlimited rounds

Checks your input so you can’t accidentally break the game

Randomly generates the computer’s choice

Gives clear win/lose/draw results

Ends cleanly when you type quit

## Why I made it
This project was mainly for practice — getting comfortable with loops, conditionals, user input, and basic game logic in Python. It’s a classic beginner project, but still fun to build and easy to expand if I want to add scoring, animations, or even a GUI later.

## How to run it
Make sure Python is installed.

Download or clone the project.

Run it in your terminal:

## Code
python rock_paper_scissors.py
